# 拾语完整静态原型 v0.13

当前版本新增帮助与反馈、本人反馈进度、管理端反馈中心，共37手机＋4桌面41画布。首版提醒渠道已确定为应用内；外部渠道后续增加，本轮未申请系统通知权限、建立自动化或发送消息。新增画面供用户审阅，不声称已实现后台。

本轮产品/运营与后端/SRE/QA两个独立角色核对反馈增量，未重新调用外部助手；此前三方报告仅为历史设计输入。当前文本、按钮与素材示例保持通用命名。

产品文案补充：界面面向通用用户，按学习目的、方式和可选时长命名，不以发起者个人的出行或生活安排命名。首页统一为“口语练习 · 自选时长”，素材示例统一为“随手记录的想法”。

2026-11-11。本稿由 Codex UI/UX 角色在真实 WorkBuddy、百度搭子和 Codex 产品/架构评审之后统一绘制。产物是可编辑静态 HTML 画布，不是业务开发；未接通上传、云端识别、音频、评测、登录、预算或发布。所有内容、计时、分数与状态均是设计样例。

## 设计计划与取舍

- 颜色：纸面白 `#FFFFFF`，深蓝正文 `#172641`，靛蓝操作 `#5557D7`，次级灰蓝 `#8590A7`，轻提示 `#F5F5FF`，警示浅橙 `#FFF8ED`。
- 字体：系统 Segoe UI 配 Microsoft YaHei UI；英语句子使用同一无衬线体系，避免额外装饰。移动正文约14—16px，英文学习句22—26px；次级说明不小于11px（导航标签10px与桌面图表刻度为例外）。
- 布局：每个手机画布一个主任务；流程内顶部返回、底部主动作。一级页保留“学习｜材料｜＋添加｜分享｜我的”；桌面为同语义侧栏和宽屏工作区。
- 本产品独特内容：自己的原件、句子、帮助条件和前后人声对比，而非课程货架、打卡金币或社交热榜。
- 沿用已选白/深蓝/靛蓝方向。卡片只用于区分原件、任务与状态；不额外引入渐变、阴影和装饰照片。

计划复核：不能把每次复习做成固定三连考试，因此 v0.8 使用“本轮：某种练习”与随时结束，不再用强制第1/3步表示必须完成。默认听说复习无键盘，拼写仅在词句本保留选修入口。分享录制不放进全局加号。

## 文件

- `index.html`：30张手机390×844与3张桌面1440×960画布，所有CSS与SVG本地内联，无业务JS、CDN和网络请求。点击锚点只能在画布间走查，不执行真实操作。
- `manifest.json`：33张画布的id、标题、分组、尺寸和建议截图路径。手机 `m01…m30`；桌面 `d01…d03`。
- `build_design.py`：静态设计生成器，修改后可重新生成HTML与manifest；不调用服务或浏览器。

本角色未运行浏览器、未宣称完成视觉渲染验收。协调者负责导出PNG、检查溢出和最终目检。

## 本轮采纳的评审意见

1. 加入空态、多题材材料库、原件核对、分单元、处理前授权和生成估算，使上传到学习可走查。
2. Agent收件纳入同一风格。示例保留“昨日回顾与今日计划”、手动/定时送入标识，但定时未创建；平台Agent依然后续验证。
3. 跟读与专业声学反馈独立展示。示例82/100明确不是82%准确率；录音不足或评测不可用不补造分。
4. 复习选项试听与提交分开；接话选项同场景，可以存在多个合理回答；答后解释记录本次文字提示，不算独立听力通过。
5. 学习侧可以进入同一录制页，保存学习记录与作品草稿分开；分享先私有草稿、字幕校对，再选择范围与渠道。
6. 外部渠道逐条显示能力和状态，已打开目标App不等于发布。公开发现分期，不阻塞私有学习。
7. 补齐用量、预算、授权、导出、删除范围，以及跨端账号进入与新版本续学选择。

## 不直接采纳的专家措辞

- “确认前不入库”不采用：允许先保存为私有待确认草稿；后续生成独立确认。
- 不采用“确认前任何步骤免费”：识别/转写也可能有外部成本，所以在相应处理前确认数据流和上限。
- 四端缺图是设计缺口，不等于需求本身不存在。桌面补图不代表四端实机验证已通过。
- “评测失败给纠音提示兜底”不意味着可以编造该录音的诊断；失败时保留未评测状态与合法缓存示范。

| --- | --- | --- |

| 提取为空/扫描疑点/部分缺失 | m07、m28 | 回原件核对、局部修改、补截图或改贴文字；不默默标完整成功 |
| ASR转写失败 | m06→m05局部变体 | 保留私有录音，解释失败，确认后仅续做转写 |

| 词典查询失败 | m12局部变体 | 保留原句与播放位置、稍后查询、回到阅读；不捏造权威释义 |
| 麦克风/相机权限拒绝 | m06、m13、m21局部变体 | 说明需要哪项权限，允许保留草稿或返回静默任务，不强制开摄像头 |
| 蓝牙/来电/后台中断 | m11、m13局部变体 | 显示暂停与已保存位置，用户确认继续，录音中断保留可用片段 |
| 跨端同步中/新版冲突 | m30、d02 | 先核查同步；继续旧版或看差异切新，不静默挪动旧进度 |
| 分享链接失效/撤回 | m24局部变体 | 新访问提示不可用；作者回分享管理；不自动恢复或公开其他版本 |

## v0.9 用户反馈调整

在v0.8三方评审基础上，依用户反馈修订两项设计；本轮由产品设计角色做增量交互核对，未再次声称三方重新评审。

- m11常显点词查词区；示例处于已选择details的暂停状态。未选择词时保留入口提示，不自动伪造所选词；词与句级播放操作分开。
- m12改为同页向上展开词卡，保留同一句与01:36位置；收起回阅读，不自动续播。两张图是同一学习页的状态，不是两个独立目的地。
- m20录制按钮明确录音/录视频，作品缩略图有视频人物占位；m21区分录音与真人视频，默认视频模式但摄像头未开启，不访问真实相机。点击开启后才申请权限，拒绝不静默切录音。
- m22预览原视频并校对字幕；私人草稿、外发确认和加号只添加材料的规则保持。
- 人物用内联SVG绘制，标明占位示意，不是真人照片或真实摄像头画面。本轮只更新静态设计。

## v0.10 上下分层听读

依用户参考改为三个稳定区域：上方完整正文(独立滚动)、下方查词面板(默认小卡，可上拉展开)、底部固定播放器与练习按钮。m11/m12是同一页小卡/展开状态；词卡不插入段落、不覆盖正文，展开时只重新分配正文高度。

保留双语/语速/单句循环、时间进度、上一句/播放/下一句、这一句没听懂、跟读/复述。两种词卡状态中这些操作始终可见；示例选择details且暂停，收起不自动续播。完整正文含六段，不把有限屏幕展示的几段当成材料全部。

正文滚动与词卡拖动独立响应，展开/收起应锚定当前句而非跳回文章开头，原型图用同一句位置示意；未实现真实拖拽。无选词时小卡显示点击正文单词的提示，选词后显示其音标释义和发音，手动收藏；不自动强开大词卡。

布局导出允许reader-article作为预期滚动容器，其余裁切与越界仍需为零。v0.9视频功能设计保持。此轮只静态布局，不调用真实音频、录音或服务。

## v0.11 词卡顺序与压缩

用户纠正：词卡应在所有播放与练习按钮下方，而非正文与按钮之间。最新固定顺序为正文→时间进度/播放控制→这一句没听懂与跟读复述→最底部词卡。此规则取代v0.10顺序描述。

默认词卡压为两行：第一行单词+美式音标+发音/收藏，第二行简短释义+点词查词展开入口。删除独立标题行、词性行与教学提示行。展开才显示例句及完整收藏操作；按钮继续位于词卡上方，正文区域按剩余高度独立滚动，不遮挡当前句。

本次只更新m11/m12静态画布及分组图；其他31页保持v0.10设计，不代表真实拖动已实现。
