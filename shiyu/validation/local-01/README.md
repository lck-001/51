# V-LOCAL-01 隔离本地契约验证

依据2026-11-12用户委托产品经理推进，以及PM-V-LOCAL-01有限决议，团队在本目录实现合成参考模型与独立测试。不是完整App开发，不连接真实模型/云/手机/生产库，不安装依赖，不读取凭据、材料库或历史录音。

- `reference_model.py`：合成内存参考模型，仅用于C01—C07语义验证。
- `fixtures.json`：合成用户、材料和故障输入，不是真实账号或专业分数。
- `test_contracts.py`：独立QA依据契约编写的负例/流程测试。
- `run_checks.py`：现有Python标准库运行器，记录逐项结果与源文件哈希。
- `results/latest.json`：执行后才生成的机器可读证据。

从本目录运行`python run_checks.py`。出现缺文件、未复核网络/系统导入或测试失败时，不写通过结论。源导入检查不等于系统级网络隔离，所有范围与来源仍需人工审阅。

内存锁/替身通过只支持合成契约语义；不是PostgreSQL锁/事务、灾备、真实第三方幂等/费用、专业语音效果、Flutter或四端设备验证。下一阶段必须分别取证。
