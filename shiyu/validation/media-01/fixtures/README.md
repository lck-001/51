# 本地媒体实验样本

全部为本项目原创合成样本，不含用户内容。生成脚本为上级目录make_fixtures.py；manifest记录实际字节和SHA256。不要自动播放。

- playback-seek-12s.wav：16 kHz、单声道、16 bit PCM、12秒；四个三秒段的频率分别为440/660/880/1100 Hz，各段最后半秒静音，可对照拖动前中后位置。
- playback-video-12s.mp4：电脑已有FFmpeg生成的640×360、24fps动态测试图，加同一WAV音轨；实际ffprobe为H.264视频、AAC单声道16kHz、12.000000秒、711270字节。FFmpeg本地完整解码退出0，不等同Flutter或手机播放通过。
- invalid-media.wav：故意损坏的非空文件；导入复制可成功，解码应失败，不得显示播放成功。
- zero-byte.wav：空文件，应用应拒绝登记为有效媒体。
- 中文 空格 导入说明.txt：合成中文文件名及文本，只检查选择、复制和取消，不提供文档解析能力。

MP4生成：已有ffmpeg使用lavfi testsrc2、libx264、AAC生成；没有下载编码器或访问摄像头/麦克风。这里只为验证基础播放/定位，不能用于验证真人发音效果、语义学习或录制质量。
