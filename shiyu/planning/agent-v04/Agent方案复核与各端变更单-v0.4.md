# 拾语：Agent方案复核与各端变更单 v0.4

2026-11-11。用户明确同意首版“外部Agent送入＋受控学习教练”，要求该改的改、该增的增。本轮产品、架构/后端、测试/安全/数据三个独立Agent分别出稿，主Agent整合并更新静态原型。没有重新声称WorkBuddy/百度搭子审过这次增量，也没有业务开发、真实Agent运行、供应商调用、来源读取或采购。

## 1. 已采用的范围

- 保留R01—R33，新增R34—R38：教练入口、可改计划、动作/停止状态、权限/记忆、外部受限送入。平台主动读取外部来源继续后期独立授权。
- 学习首页内嵌教练，不新增一级导航。加号仍只添加材料；听读正文→播放/练习操作→最底部两行词卡保持；录音/真人视频继续在学习/分享复用。
- 一个有限学习教练协调已有能力，不每轮开一群大模型、不开放任意电脑操作或工具市场。
- 只在用户明确批准的本次材料/版本、动作、学情和用量内工作，默认不读全库。计划可调整，用户最终确认版本优先；教练不可覆盖事实、专业分数或费用。
- 公开/代发/删除/扩大来源读取等不作为首版教练执行工具；需要时进入用户自己的专门流程。不是模型收到“同意”文本就有执行权。

## 4. 原型更新 v0.12

新增m31—m35，修订m02、m10、m26、m27、d02；合计35张移动端＋3张桌面，38张静态画布。主页、计划、权限有明确入口，示例与真实未接入不混用。

权限/费用的首用状态：上限未设置时不启动规划模型；用户可查看计划示例或直接体验已有示例练习，不能据此跨过真实教练准入。规划模型调用本身也计用量，使用已有材料不等于教练免费。

原型复核发现并修正：

1. m27缺教练管理入口→已补到m34。
2. 由未设上限的权限页进入示例计划后，“按计划开始”可能被理解为绕过准入→主按钮改为确认权限/用量后开始；次按钮明确为示例练习。
3. 原预算页只描述材料生成→改为按当前批准计划核算，并说明教练规划计入用量。

主Agent已重新导出修改页并做布局和文本复核；这不是运行时安全测试。停止/撤权后的详细回执、正式连接认证、模型调用与实际费用仍需实现及验收，不将锚点走查当真实操作。
