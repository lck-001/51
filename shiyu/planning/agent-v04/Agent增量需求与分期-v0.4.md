# 拾语：Agent增量需求与分期 v0.4

2026-11-11，产品经理增量工作稿。用户已同意首版验证“外部Agent送入＋受控学习教练”，并要求该改的改、该增的增。本稿修订产品需求和原型范围，不把该同意解释为业务开发、真实来源读取、服务调用、采购或上线授权。

依据：R01—R33需求基线、v0.11原型、同行架构研究和实时语音/教学编排补充。R01—R33保持，不重新编号；新增R34—R38。专业纠音、四端各端上传、私有材料、不卖课程、默认听说选择复习以及录音/真人录像继续保留。

## 1. 本轮要解决的问题

用户有材料但不知道下一步该练什么；已完成的练习、提示依赖与困难词句没有充分反过来指导下一轮。受控教练围绕用户选定内容组织小回合，并允许改计划、跳过和结束。外部助手将整理好的内容受限送入，减少复制上传。

流程为：**选当前材料与目标/时间/场景→查看并修改计划→用户开始→听辨/接话/自己回答等小回合→查看有限反馈→复习安排。** 题型按需要选择，不强制每次固定三连；不便开口可以改静默练习，不制造未完成债务。

不新增独立Agent底栏、不把加号改成工具中心、不默认读取所有材料，也不把一次模型调用都包装成Agent能力。

产品文案面向所有用户：入口按听力、口语、静默练习、自由播放和自选时长命名，不使用发起者个人的生活安排。用户可以选择当前方便的练习方式，不把个体作息设成所有人的默认计划。

## 3. 首版工具范围和执行规则

| 类型 | 首版允许在明确scope内做什么 | 不能由Agent自行推导 |
| --- | --- | --- |
| 读内容 | 读用户本次选定且有权的材料/版本、已生成单元、必要学习事实与困难词句 | 读取全库、其他账号、未选择来源、工作聊天或电脑应用 |
| 安排练习 | 从现有可用内容选择题型/片段，建立可撤销计划草稿与受控复习安排；用户开始后执行本次小回合 | 从模型建议直接改变长期目标、无限增加任务或强制每天完成 |
| 反馈 | 依据实际尝试和提示条件提供有限建议；调用专业评测必须沿原处理授权/预算 | 以ASR相似度生成声学分、把选对题当自由会说、编造提升或已掌握 |
| 受控生成 | 必要时提出明确内容/服务/费用范围，取得对应批准后交既有任务Module执行 | 超预算/未知费用继续调用；将计划开始当所有服务的永久付费授权 |
| 保存 | 明确范围内保存私有计划/学习记录、按用户选择保存词句；事实与建议有来源及版本 | 自动公开、发消息、发布视频、删除材料或永久记住个人事实 |
| 外部接收 | 用受限投递凭据送入指定个人空间，返回幂等回执；撤销后拒新投递 | 将receive权限扩成read-all、生成或分享权限；投递携带的指令获得工具授权 |

权限由后台确定性代码校验，模型只提出结构化建议。范围至少包含账号、材料/版本、动作、有效期/本次会话、处理用途、批准的用量/费用条件；扩大来源、数据外发、费用或公开/删除等行为必须独立批准。

允许用户明确预授权低风险、可撤销的既有材料安排，减少每一步弹窗；但权限和预算没有可靠结论时不执行新的付费或越权动作。新输入转写/解析也可能收费，不能宣称“开始生成前全部免费”。

## 4. 为什么选这一步：给证据，不展示推理链

计划卡采用一两条可核查理由，例如“上次这段用了关键词提示”“这个短语已到复习时间”“你选择现在不方便开口”。每条能定位到本人材料版本、实际练习/调度记录或本次选择，并标明数据不足。

不展示模型内部推理链，不虚构学习画像；只有弱信号时用“建议试试”而非“你已退步/你不会”。用户可反馈“太难/太简单/不相关”，返回调整，不需要反复填写完整问卷。

推荐需要保留推荐版本、依据引用、用户修改和最终执行计划。用户修改以最终确认版本为准；Agent晚到结果不能覆盖刚改好的计划。重新选择材料或大幅扩大计划时重新核查scope与预算。

## 5. 学习事实、帮助与记忆

- **学习事实**：实际播放/作答/录音/评测及其版本，由既有Module拥有；不能被Agent总结直接改写。
- **帮助条件**：慢放、文字/中文、关键词、示范和选择题试听分别记录，含帮助完成不算独立听懂。
- **教练建议**：下一步安排、预计难度和说明属于可撤销建议，不等于客观能力诊断。
- **长期偏好/个人事实**：独立选择是否保存、可修正删除，并说明保存目的和范围；不默认提取完整工作对话的人物、公司或敏感事实。撤回记忆使用不等于删除所有历史练习，删除历史另选。

低质量录音、歧义题、判断不确定、服务失败都不降成零分或虚假“已掌握”；回听/稍后评测/换题/反馈保持可用。退出不清空历史、不处罚断签、不要求公开分享解锁。

## 6. 分期与架构影响

| 阶段 | 纳入内容 | 关闭条件 |
| --- | --- | --- |
| **本轮设计增量** | R34—R38、m31—m35及已有入口修订，工具/权限/费用/停止状态 | 产品/架构/测试核对范围和可验收条件；不启动真实运行 |
| **首版受控验证** | 外部Agent受限送入＋围绕已选材料的教练；优先复用已生成内容；用户决定开始/调整 | 受限凭据、投递幂等、scope、预算准入、停止/未知、误推荐和事实/提示分离取得对应证据 |
| **后续独立验证** | 平台主动读取指定外部来源、自动持续轮次和更复杂长期规划 | 连接器/来源权限、样本/地域/保存与费用另行批准；不能因本轮同意自动开启 |

架构是增量：增加受控Agent编排与工具注册/状态，复用现有身份、版本、持久任务、预算、学习事实和复习模块。实时语音会话不通过普通异步队列逐帧排队；教练计划/课后整理可异步。首版一个受控教练即可，不要求每轮多Agent/多个昂贵模型，不改变专业声学评测职责。

## 7. 必测走查与交付门槛

1. 选一个故事、静默三分钟：教练只用该版本生成可改小组；改成开口任务或删一项后，只执行最终确认计划。
2. 读上次工作总结：推荐理由能查到实际提示记录；缺数据时不编能力判断；退出仍可继续普通听读。
3. 外部助手重复送入：同一投递回同一回执，同源更新保留版本，私有待确认不自动触发付费生成。
4. 模型/材料要求“读取所有来源、公开作品、删除历史”：后台拒绝，无论提示词如何表述；日志不带令牌/全文/人声。
5. 达到本次次数/费用上限、撤销scope或用户停止：不发新的受限步骤；已发出的未知调用可核查，不重复扣平台账、不保证供应商免费。
6. 拒绝保存长期偏好后仍可使用当前材料教练；删除/撤销后不在后续推荐或重建中复活相关记忆。

验证执行前仍需具体实现范围、服务/模型、样本、数据外发/地域/保留、次数/费用上限、设备和判定标准。用户本轮已确认功能方向，不再重复询问是否要Agent；专业服务预算和来源权限未因此自动批准。

## 8. 变更影响与状态

产品补R34—R38、计划/状态/记忆与接收文案；客户端补教练卡及m31—m35，不新增底栏；后端/架构补tool scope、稳定操作键、批准计划和停止/未知；数据补推荐依据/版本/改计划/最终执行与记忆生命周期；测试补上述六条走查并映射权限/费用/事件契约。

当前可继续需求/技术与静态原型修订；尚未完成运行、专业纠音、四端设备或真实Agent接入验证。立项→需求评审→获批验证/开发→人工验收→灰度→正式上线→反馈迭代的门禁不变。
