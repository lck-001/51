# 候选确认与学习版共用一个提交

学习候选、固定校对修订的确认映射和学习版共用 LearningStore 的权威快照。确认在 Store 内生成记录并一次提交，避免跨存储“学习版已创建、回执尚未保存”后重试重复建版；不让 Python 接收端或 MCP 代理直接修改 Dart 文件。材料固定版本仍经 MaterialStore Interface 核对，二者的 ID 不作猜测映射。

新来源与候选使用 schema 2。新客户端保留读取 schema 1 的能力，在接受新候选前先将备份、再将主快照写为 schema 2；升级后不支持旧二进制回写。应用保持单 writer，由 App 级进程锁阻止两个遵守新协议的实例；该锁不声称能阻挡已在内存且不遵守协议的旧 writer，升级前旧学习实例须先结束。

首个分片只接文本候选，确认后无音频即部分可读；音频仍在后续分片，不能用跨材料/学习文件的弱回写或静音夹具冒充朗读闭环。传输入口只交付候选，不拥有学习确认或发布权限。
