# M14 Android 模拟器有限验证计划

状态：计划已部分执行，实际结果见 [M14执行记录](M14-emulator-results.md)；本文不代表测试通过。仅验证既有媒体实验 APK，不扩展产品实现。

## 准入与隔离

- 候选环境：官方 Emulator 37.2.13、API 36 AOSP default x86_64 rev2；记录实际安装版本、镜像、启动参数及渲染模式。HypervisorPresent 与 WMI 虚拟化标志需结合启动日志解释，不能据单一标志判定 BIOS 关闭。
- 使用独立 ADB 服务端口 5038；所有设备命令显式绑定 `emulator-5558`，先确认目标为本次虚拟设备。保留 `--one-device` 非 USB 哨兵隔离；不执行无目标安装、全设备操作或 USB 授权。
- 相机仅用虚拟场景/合成图；关闭主机麦克风输入和 webcam 映射。不得为测试打开真实采集、导入私人文件或登录个人账号。
- 输入仅为已知合成 MP4/WAV、中文空格 TXT、损坏及零字节文件。预置到虚拟设备共享文档区后，由系统文件选择器导入，不能以直接写入 App 私有目录代替 SAF 用例。

## 最小用例与判定

| 顺序 | 操作 | 通过条件与证据 |
| --- | --- | --- |
| 1 | 安装前核对 APK | 核对本次冻结版本、包名、SHA256、大小、签名、min/target SDK 与权限；记录实际安装 APK，不能沿用旧摘要。模拟器系统版本/ABI兼容 |
| 2 | 安装、冷启动 | 安装退出成功且目标包/版本匹配；首屏可操作，无崩溃、无主动采集/索权。记录界面和限定时间段错误摘要 |
| 3 | SAF 导入与取消 | 系统选择器导入合成 MP4/WAV；中文空格名可显示；取消不新增条目且按钮恢复。已知合成输入与复制结果可核对大小/摘要 |
| 4 | 播放、暂停、定位 | 视频画面时间码与进度前进；暂停后稳定、续播推进；点击/拖动前后定位符合目标时间附近。WAV 验证时长/进度；无实听证据不写声音正常 |
| 5 | 无效输入与恢复 | 空文件不登记成功；损坏媒体报解码错误；再选有效媒体可恢复。文档复制成功不等于内容解析实现 |
| 6 | 权限拒绝 | 分别拒绝录音/相机请求，不进入采集，不循环索权；导入与播放仍可使用。永久拒绝若可复现则单列；不以虚拟权限等同真实硬件行为 |
| 7 | 可选虚拟相机 | 仅在确认无主机输入映射后，用虚拟场景验证预览/录像/停止与保存；背景切换后不自动重开采集。无音源只证明流程，不能证明语音录制质量 |

现有实现后台统一暂停；本轮可以记录实际行为，不能将其标为 M13“主动音频锁屏继续”验收通过。后台、焦点与系统媒体控件仅作观察项，后续实现与逐端验收另列。

## 留档与退出

每项分为通过、失败、未测；记录具体版本、步骤、预期与实际结果。截图仅含合成内容；日志按包及时间窗口截取并脱敏，不归档整机 logcat、AVD/ADB 本地配置、设备标识、主机路径或私人媒体。模拟器卡顿需记录渲染/虚拟化条件，不能直接归因产品性能。

结论最多为“该镜像、该版本的模拟器有限用例通过”；不能替代 Android 真机、OEM 文件提供器、蓝牙/通话、真实相机麦克风、声学评测或锁屏可靠性结论。完成后关闭测试虚拟设备及本任务私有服务，不清理其他任务进程。下一步依据失败清单决定修复或补测；真机验证继续延后，无需用户选择技术参数。
