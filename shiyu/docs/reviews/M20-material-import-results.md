# M20：TXT／Word 私有材料导入

2026-11-18。本批实现 TXT 与普通 DOCX 在本机导入、提取预览、校对、保存私有草稿、确认固定版本和重启恢复。导入不自动翻译、配音、计费、分享或生成学习版本；PPT／PDF仍在已批准队列中。

## 实现与范围

- `packages/material_import` 提供无 UI 的有界文本提取与会话合同。TXT 严格读取 UTF-8、带 BOM 的 UTF-16，换行正规化 LF；DOCX 支持正文段落、换行、普通表格与标准命名空间。版式、图片、页眉页脚、批注/脚注/尾注及部分嵌入或修订内容不作为完整提取结果，预览给出遗漏提示。
- App 拥有选择器、私有临时副本、可终止解析 worker 和取消；Windows分块复制，Android 使用独立 SAF 流式读取，不经原插件整文件分配。原生 URI 仅接受 `content://`；未增加全盘存储、相机或麦克风权限。
- 页面只收到不含路径的预览与会话。保存前重新核源 hash，准备源文件及提取来源 JSON 两个真实制品，经既有 MaterialStore 保存并回读后才能结束会话；校对后的草稿和原始提取文本分别保留依据。
- 一次只保留一个导入预览。当前预览未保存/结束时不能重选文件，避免取消新选择时丢掉旧来源；手工编辑在选择取消或提取失败后仍保留。保存在途禁止切页，旧回执和换账号不会写入新编辑。

`archive 4.6.0` 与 `crypto 3.0.8` 沿用已锁版本，定向新增 `xml 7.1.0 / petitparser 7.1.0`；没有升级无关依赖或新增本地 HTTP 服务。依赖锁已保留，详见架构记录。

## 资源与取消门槛

本批候选单次限制为源20MiB、条目16MiB、累计实际解压64MiB、XML8MiB、正文200000码点，另有条目数、XML深度/事件/属性上限。来源 JSON 独立上限2MiB，4096字节分块编码且先完整有界编码再注册任何制品。达到上限整体拒绝并建议拆分，不静默截断。这些是当前工程切片限额，不取消长材料目标，也不是所有设备的容量或总 App 内存/磁盘配额证明。

ZIP使用懒目录筛查、元数据一致性、实际解压计数及自有 CRC/长度校验，不向任意路径解压；XML禁止DTD/外部实体并实际限制解析。取消/超时会终止解析 isolate；原生读取未确认结束时保持占用。只清理本会话实际创建的临时文件，删除失败不假称已清理。

## Android实际链与候选身份

既有两个候选分开留证：`4039…e2b5` 的真实TXT/DOCX、保存来源、冷启、取消/损坏/空/已知大小超限共75项标量断言通过；`64650…358e` 的升级保留、预览禁重选、保存/确认/冷启共32项标量断言通过。这些数目不是独立测试用例总数；也不是全部恶意解析矩阵都在Android运行过。

来源预算补丁更新候选为 `0.1.1+2`，APK 153709927字节，SHA256 `335578fba523bc3d423626cddd3eb7ab560bc874d18e022cb97b313d9f7f711b`。该候选已构建并实际完成35项标量检查：普通DOCX经真实SAF、校对、保存两来源制品、确认及冷启通过；43782字节长路径样本预览完整，但保存明确超限，零新增制品/草稿/版本，原件和已存材料不变，放弃后stage为空。独立QA逐项核对APK、原始Store/fixture/hash/UI及日志收尾后有限验收通过；未借用旧候选矩阵充当新包全量重跑。

Windows最终预算补丁也在独立目录 Debug 构建成功；没有启动主机窗口或选择器。各次Android测试后均核对归属并关闭自有AVD和私有ADB，专用端口全空、自有模拟器进程0；最终包采样崩溃日志为空。真实手机、Windows原生选择器人验和Apple平台仍待后续证据。

## 限定与下一步

未知/谎报SIZE或阻塞的真实Provider、Windows选择器人验、真实手机及Apple平台未验。进程异常退出前的私有stage还没有持久会话索引/历史安全回收；已注册但未引用的私有制品不盲删，不宣称崩溃零残留或跨历史会话总磁盘上限。
