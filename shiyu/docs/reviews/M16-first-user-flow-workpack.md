# M16：首个用户业务闭环实现包

产品经理推进单；承接已批准的v0.13/R01—R41，不重新讨论产品定位或框架。仅写本文件，未操作主界面、设备、服务或素材。

## 1. 当前起点与下一项

M13 Core已有52项纯策略回归；M15已有两条Android原生后台链路及Windows Open-only证据。它们不证明完整产品、声音质量、四端或专业纠音已验收。
`validation/playback-01/lib/audio_material_store.dart`目前只在内存Map保存路径/名称，owner固定为local-device、revision固定为1；复制文件不等于材料库已持久化。
**下一项优先做“材料/版本持久化＋受限送入”，随后串学习版本与既有Playback Interface；不要再用媒体实验次数代替业务进展。**
不修改用户正在使用的录制会话，不自动启动App/文件选择器/模拟器/浏览器。可在后台写模块、运行合成与临时目录测试；真实人验/外部授权节点到达再停。

## 2. 目标与有限闭环

粘贴文字或受限Agent投递→本人私有待确认草稿→校对并创建不可变材料版本→建立学习版本/单元/句锚点→关联有来源的音频→用既有播放器打开→保存并重启恢复同版进度。
首轮用自造故事和已明确标注来源的合成双语/音频完成结构联调，不读历史工作消息或真实录音。仅完成这条结构链不称“中文自动转学习内容已完成”。
四端、文档/PPT/PDF及其他来源完整目标保留；本包先实现文字/外部整理文本的纵向链路，格式Adapter和实机按原顺序补齐，不删除或宣称已支持未做格式。
不扩课程商城/学习包、公开发现、站外代发、平台主动抓取。基础真人录像继续保留，当前素材工作包不改采集权限。

## 3. 实现优先级、代码路径与交付

下列为建议新路径，现仓仅有playback_core等实验；Root可按模块命名调整，但不能另开第二套权威源码。

| 顺序/主责 | 建议代码落点 | 本包必须交付 | 验收门槛 |
| --- | --- | --- | --- |
| P0 客户端/存储 | `packages/material_core/`；随后将实验`audio_material_store.dart`改为窄Adapter | 材料ID、owner、不可变revision、制品引用和本地manifest；写入/读取/列出/修订/恢复Interface，路径留私有Adapter | 新进程可恢复索引；坏/截断manifest、丢文件、重复导入明确返回状态；原始文件不被覆盖；不靠内存Map判持久化成功 |
| P0 后端/接收 | `services/backend/src/shiyu/intake/`与`materials/` | 受限投递契约与持久回执，服务端身份绑定owner；delivery_id幂等、内容指纹与同源更新、私有待确认版本 | 重投返回同一回执；同ID不同内容拒绝冲突；越权读取/receive扩大为generate/share均拒绝；重启后去重和更新关系仍成立 |
| P1 后端/学习内容 | `services/backend/src/shiyu/learning/`；共享版本Schema | 校对生成新revision，学习版本指向确定材料、单元/句锚点、来源和内容状态；区分待生成/就绪/部分失败 | 旧版本仍可读；局部修改不把旧音频/题目错挂新句；未生成文本不得标就绪；人工/合成内容不能标AI已生成 |
| P1 客户端/数据 | `packages/learning_core/`及既有`packages/playback_core`外部适配处 | 带版本的播放解析与进度持久化；绑定owner/material/learning/media版本，Open仍默认暂停 | 重启不自动Play；错账号/缺制品拒绝；旧进度不能按百分比搬新版；播放意图/实际/暂停原因沿M13协议 |
| P1 测试 | 上述模块的Interface测试及`services/backend/tests/` | 两个合成身份、重复/更新/崩溃恢复/版本冲突/未授权/未生成/缺文件的独立回归，附实际命令和结果 | 临时目录可重复；检查真实落盘和重启，不复写私有条件；失败不跳过或换成成功占位 |

本地存储Adapter只承担单设备草稿/缓存，不能当PostgreSQL多租户/事务/预算权威已通过。若当前无PG环境，可先完成后端领域与持久化Interface/适配源码和隔离测试，PG迁移/并发实测明确记未执行；不为跑演示静默换定生产数据库。
HTTP路由尚未实际运行时，只报告模块/契约已测，不称服务已接通。合成身份/投递凭据不等于真实账号认证；实际Agent连接/密钥签发与运行回执单独列证。

## 4. 公共契约不变量

- 接收成功只代表草稿持久保存，不自动提取/翻译/计费/学习/分享；计划与后续生成由用户确认的scope及预算准入。
- 存储路径、原文件名、完整正文、令牌和音频不进公共Git、系统媒体元数据或通用日志；测试只用合成fixture和脱敏ID。
- owner来自已验证调用上下文；客户端字段不可自行指定另一个用户。无真实身份Adapter时禁止公网暴露本地验证服务。
- 材料/学习/媒体/题目与进度有版本锚点；新内容先存草稿，用户校对后建新版，不原地覆盖历史或悄悄合并跨用户内容。
- 任务与费用归后端权威；超时未知先核查，不能把重试按钮直接映射为再发一次供应商调用，不能先放钱后补授权。
- 用户界面最终保持正文→播放/进度→练习按钮→最底部两行词卡；本包后台实现不借机改已确认布局。

## 5. 真实资源与效果门禁：不可用占位替代

| 路径 | 可先后台完成 | 何时必须取得真实资源/人验 |
| --- | --- | --- |
| 中文变地道英语/出题 | 处理计划、输入版本、Adapter、质量与未生成状态，合成契约联调 | 宣称自动生成可用前，提交具体LLM/地域、样本/用途/保留/次数费用上限并取得批准；核对事实/自然度、合理多解和提示泄露，模型自评不能作唯一通过证据 |
| 英语音频/逐句对齐 | 媒体引用、句锚点、已有合法音频播放链路 | 宣称自动TTS和逐句同步前，核清音色/公开权利、服务/数据/费用并实际生成检查；人工合成fixture不证明供应商支持或真实音质 |
| 专业发音/自由表达 | 原音引用、capture_profile、质量/未评测状态、结果持久化契约 | 真实Speech服务与有限样本批准后，验证任务支持、无效样本拒评、重测与可行动反馈；ASR文本相似度、固定82分或mock不能算功能 |
| 客户端交互/四端 | 可分析/构建及模块回归，保留平台Adapter范围 | 用户可验主流程时给具体候选包/步骤；真实听音、设备采集、Android真机/OEM与Apple分别留证，不控制当前主界面代验 |
| 外部Agent真实送入 | 服务端受限接口与重复/越权回归 | 实际客户端工具、账号归属、可撤销scope和持久回执验证后才称接入；禁止借此读取全部终端记录 |

到这些节点先由团队准备具体可审阅验证单，不反复让用户选框架参数；未获该节点授权时继续无依赖存储/版本/契约，不伪造效果或无限等待。

## 6. 本包完成定义与后续顺序

**M16完成**：P0存储与送入、P1版本与播放器适配有可运行的后台/模块证据；重启、双身份、幂等和失败恢复经独立QA；需求映射至少R03/R05/R07—R12/R26/R29/R30/R38明确。API/PG/真实资源未验部分逐项列出，不用一个“全通过”覆盖。
**下一包**：有限真实LLM→TTS/对齐→专业Speech效果按各自授权与依赖推进；再接v0.13实际学习界面、复习和受控教练。教练必须消费真实已就绪版本，不得对未生成内容假装安排成功。
**并行债务**：M15自然结束、Seek、真正锁屏、关闭竞态和硬件释放矩阵继续跟踪；不必等全部四端实机才写存储，但产品背景播放承诺仍不能提前验收。
当前阶段：M15有限集成之后的M16用户业务闭环实现准备；建议Root先实现`packages/material_core`持久索引及其重启/损坏恢复测试，再做后台受限接收与材料版本纵切。当前无需用户操作；遇真实外部数据/费用/设备/人验节点再按具体包请求。
