# M19：从已确认原文到有来源学习内容的生成工作包

2026-11-18，产品推进单。承接 M16/M17 的固定版本与来源约束、M18 的 C0/C1 交付门槛，不重开原型、课程商城或手工内容编辑器。本文件是下一实现包与验收要求，未执行生成、外发、供应商调用或费用动作。

## 1. 现在缺的不是播放器，而是可信生成链

当前后端 `IntakeService` 只接收、校对和确认文字；`materials:receive` 不含生成权限。Dart `LearningStore.createVersion` 能创建学习版，但来源只有 `manual/synthetic`，也没有生成任务、供应商来源与预算权威。应用不会因为保存中文就自动得到英语和音频。

需要补齐：已确认原文版本→确定的生成计划→已准入的执行→保留事实的美式英语与双语句结构→真实语音及经验证的句时锚→有来源的固定学习版。任务状态、供应商是否实际执行、预算状态、产物可否使用，必须分别记录。

本轮先交付 **M19-A 本地可验证的持久任务纵切**：创建/查询/取消、计划与能力校验、幂等、预算预留、执行不确定性、产物校验与结果清单。默认不联网，独立测试可用明确标记的受控 Adapter。它不是中文转换已可用；后续 M19-B 才接实际供应商和学习版导入。

## 2. 不变量与最小输入

任务只能绑定可信调用方拥有的**已确认**材料版本，不能接受任意 `owner_id`、草稿正文、客户端给的已翻译标记或待变更的草稿作为权威。先沿现有 `TrustedCaller` 的服务器验证链；合成身份仍不等于真实登录。

建议对调用方保持三个业务操作，名称可由后端架构师调整，不增加通用工作流平台：

```text
create(caller, material_version_id, request_id, options) -> JobView
get(caller, job_id) -> JobView
cancel(caller, job_id, expected_revision) -> JobView
```

- `options` 首包只含必要目标：`en-US`、内容策略版本、音频规格/音色配置引用及是否需要逐句定位。原文事实必须保留，简化解释不能静默替换原意；不接受随意工具调用、外链抓取或“顺便分享”。
- `request_id` 用于同 owner 下持久幂等。同键同输入返回原 job；同键不同材料/配置返回冲突。新材料版本或明确重新生成是新请求，不能自动沿旧预算再执行。
- 创建时读取并冻结材料内容指纹、材料/版本 ID、计划版本、目标能力和配置指纹。客户端只提交引用，不能篡改供应商地域、价格、预算或批准状态。
- `JobView` 只返回任务 ID、材料绑定、revision、阶段/状态、稳定原因和已可用结果引用。完整正文、供应商原始错误、密钥、私有路径、签名 URL、账户/账单细节不进通用状态或日志。
- 查询、取消分别校验权限；接收权限不能升级成读取/生成/取消。跨 owner 按既有不泄露存在性的方式拒绝。

本包可先做 Service Interface 与真实临时持久 Adapter；不为了演示启动公网 API、部署队列或接普通用户。对 HTTP 暴露与真实身份接入独立准入，不能把模块调用当服务已连通。

## 3. 一个任务状态＋一个当前阶段，不制造假进度

| 状态 | 含义与允许动作 |
| --- | --- |
| `blocked` | 缺能力、实际授权/额度或资源；可查询/取消。创建任务不意味着请求已出站；批准条件齐备后才能经受控转移进入 queued |
| `queued` | 计划和准入已校验、预算已预留，尚未开始当前执行；取消可直接终止并释放未使用的预留 |
| `running` | 某一阶段已被 worker 原子领取，attempt 与操作标识先持久化；不是已生成或已扣款证明 |
| `cancel_requested` | 执行中已请求取消，禁止开始后续阶段/发布。未获得停止或调用结果前不写“已取消”，也不自动退还可能已用额度 |
| `uncertain` | 已可能出站但结果/用量不明，或崩溃后无法确定执行结果；冻结有关预留，先核对供应商状态，不能重新发一次当作查询 |
| `cancelled` | 已确认不会发布本任务结果；尚有未结算用量时预算仍可 held/unknown，不把“取消”解释为没收费 |
| `failed` | 明确失败，原因稳定可读；重试需证明前次未重复执行/未超限，按计划生成新 attempt，非按钮直接重发 |
| `completed` | 本任务阶段产物已校验、固定结果清单已持久化；不自动代表客户端学习版已导入、声音已听验或英语自然度通过 |

阶段只表达当前工作，如 `translate`、`synthesize`、`align_validate`、`package`。阶段成功可留可追溯引用，但缺音频/时锚不能把整任务写 completed 或学习 ready。任务 revision 用于并发/取消冲突，worker 领取/完成要有 lease 或 fencing 机制，不能因两个 worker 同时轮询重复提交。

本地“受控 Adapter 的 completed”需在结果中明确 `execution_kind=fixture`，不写 provider-generated，不自动进入普通用户学习列表。UI 可显示“测试完成”，不能显示“英语学习内容已生成”。真实 provider 结果缺失时保持 blocked/failed/uncertain 等实际状态。

## 4. 内部执行与供应商能力准入

worker 通过小 Interface 执行冻结计划；供应商 Adapter 只承担能力查询/已准入执行，以及存在时的查询/取消，不增加 Agent 任意工具权限。外部操作前必须持久化 attempt、幂等操作键、预留、准入配置版本与输入指纹；响应处理绑定 job/阶段/attempt/fence。

供应商能力描述至少覆盖：

- 操作类型（翻译/改写、语音合成、时锚/对齐），实际支持的语言、输出结构/格式、长度限制、音色及其使用权。
- 真实供应商/模型或语音版本、配置版本、地域/数据处理范围；未知或不能证明不作为已支持。
- 能否提供句/词时间标记；不能时需显式对齐阶段。文本长度比例、均匀切时长不算真实语音对齐。
- 请求幂等、查询、取消是否真实支持；不支持查询时，超时未知不能靠本地重发实现“恢复”。取消只尽力时如实保留 cancel_requested/uncertain。
- 计量单位、已核实的费用/免费量适用范围、上限和是否存在最小计量/取整。未知价格不是 0；F0 Speech 发音评测准备方案不是 LLM/TTS 已准入证明。

本包不选择或开通付费厂商，不承诺某家免费服务可覆盖全链；未知能力一律阻断该操作。实际选择前提供小样执行包：样本来源/哈希、用途、地域、次数/长度、保留方式、费用上限和退出条件，再走真实资源准入。

## 5. 预算与取消：不能靠重试绕过

- 预算来自受控授权记录/服务配置，不由请求体自报；按 owner/授权批次/币种/计量单位记录上限、预留、已确认使用、未知占用。不同单位不能直接相加抵扣。
- 创建本地任务可以 blocked；只有计划所需能力/授权具备且预算能原子预留时才准入执行。并发任务不能各自看到同一完整余额。
- 免费同样记录调用次数/长度上限和免费适用证据；赠金或延迟 0 账单不等于永久免费。告警不是硬限额，未知费用不自动填零。
- 出站前取消释放未使用预留；出站后取消不得抹掉 attempt/账本，晚到结果先核对当前状态，取消获胜时不发布学习内容。存在真实用量则照实结算，未知继续持有并明确待核对。
- 崩溃时处于“已记 attempt、可能出站”窗口，重启先恢复为 uncertain/待核对；供应商无可靠查询/幂等保证时不得自动补发。租约到期不等于供应商未执行。
- 重试不删除任务/账本、不换 job/request_id 偷渡次数。经核对允许重试才建立新 attempt 和剩余额度检查，保留历史关联。

以上先用单机真实持久与原子事务验证，不冒称 PostgreSQL、多节点或分布式预算已通过。沿已有后端存储 seam，SQLite 仅验证；PG 迁移/并发需实际环境独立补证。

## 6. 产物与学习版交接

结果清单至少绑定 owner、material/materialVersion、输入内容指纹、job/attempt、计划/Schema 版本，并列出：双语句结构与稳定句序、实际音频制品 SHA/长度/格式/时长、逐句起止和产生方式、每阶段真实来源/模型或语音/配置引用、校验结果/失败原因。来源字段只能由执行链写入，不接收客户端自称 provider-generated。

产物先临时持久化并逐项校验，再原子提交不可变清单；数据库事务不包住长时间外部调用。崩溃留下的临时制品可诊断/隔离，不能误显成功；不得清空存储来“恢复健康”。正文和音频保存在私有制品层，不放进普通任务事件、日志或公开 Git。

当前 `LearningStore` 只接受 manual/synthetic 且本地文件为权威之一，因此**不可由 Python worker 直接改 Dart manifest、混用两端 material ID 或把供应商结果标成 manual**。M19-A 先输出可校验清单；M19-B 在单独 Schema/兼容性评审后扩来源并做窄导入 Adapter：

1. 验证已授权 owner、原材料/版本/指纹与本地材料绑定；无映射则拒绝，不猜测对应关系。
2. 校验制品和句时锚，通过现有 Store Interface 注册制品/创建新固定学习版；服务结果只作候选，不直接标客户端 ready。
3. 导入以 owner＋job/result ID 持久幂等；同结果不创建多个学习版，同结果 ID 内容变化拒绝。失败不覆盖原学习版，不把旧百分比搬新媒体。
4. 只有 LearningStore 的实际结构/媒体校验通过才进入该版可用状态；英文事实/自然度与音质仍需独立内容验收，不因容器合法就判语言通过。

不新增面向用户的手工双语/音频编辑器来绕过这条生成链。原有测试夹具继续隔离，合法手工内容只能按真实来源进入工程验证。

## 7. M19-A 最小实现与独立验收

建议落在既有 `services/backend/src/shiyu_backend/` 的 generation 模块与对应 tests，复用可信调用方、存储事务和稳定错误风格。三类角色明确：调用方 create/get/cancel；worker 领取/执行/核对；Repository 负责原子状态/预算/清单。不要为本包先搭通用调度平台、消息总线或新部署体系。

| 场景 | 必须看到的实际证据 |
| --- | --- |
| 创建/跨账号/草稿 | 合成身份真实持久；仅已确认本人版本可创建；receive-only、他人版本与伪 owner 拒绝且不泄露；不同 owner 的 request key 不串单 |
| 幂等/更新版本 | 重启后同 request 同 payload 返回同 job；同键换原文/配置冲突；新版单独 job，原任务输入/产物不变 |
| 默认无资源 | 未注入供应商/授权/预算时保持 blocked，调用计数为 0，无联网/生成音频/写学习列表 |
| 能力/预算 | 不支持 en-US、无合法音频/时锚能力、未知计价与不足额度均不出站；并发预留不超限；重启仍保留已用/未知占用 |
| 受控执行 | 原创文本与受控 Adapter 验 attempt/阶段转换，命令返回不等于产物完成；结果明确 fixture，无 provider-generated，无用户学习 ready |
| 取消/晚到结果 | queued 取消不执行；运行中取消不提前假称停止；取消获胜后的响应不发布；重复取消和过时 revision 有确定行为 |
| 超时/重启 | 出站不确定、崩溃窗口、重复 worker 领取与过期 fence 不重复调用/提交；未知不自动释放预算或重发 |
| 产物坏/部分成功 | 缺英文、错材料/owner、音频损坏/hash不符、缺/倒置/越界时锚、只有英文无语音均不完成；成功阶段引用可查而非整包假就绪 |
| 原子结果 | 制品先写/清单后写的故障点、重复完成、同结果ID不同内容均有回归；新进程回读清单/账本，不用内存Map冒充持久性 |
| 隐私/错误 | 公共任务/异常无原文/音频/私有路径/密钥/原始供应商内容；只输出稳定原因，受控本机临时文件收尾 |

完成定义：小 Interface、真实临时持久和进程重启证据、上述失败/取消/未知/越权测试、独立 QA 与架构评审、敏感/生成物审计、功能分支交付。结果分别注明已实现/静态/本地实跑/真实供应商未验；不得给 M19-A 写“自动翻译配音已完成”。

## 8. 接下来怎么走

Root 可立即安排后端架构师审小 Interface 与既有 Repository 的衔接，随后实现 M19-A 并让独立 QA 验收；不等用户回复 F0、不发新账号催办。M19-B 的内容来源 Schema、候选包导入与前端任务状态可在无资源情况下设计/实现失败路径，真实成功路径仍待有限样本准入。

用户目前没有需要立即操作的事项。真实 LLM/TTS/Speech 资源、数据/费用条件、本人听说体验或发布决定到达时，由团队先准备可审阅的具体执行包，再集中请求必要参与。无账号不是本地研发停工的理由，已写 Adapter 也不是供应商可用性的证明。
