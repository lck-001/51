# C3-G2：双许可授权与真实媒体候选界面

2026-11-24。本片只修改三个现有 UI 文件及对应测试，复用现有 Core、受限助手通道和私有存储工厂。固定源码的独立完整 50 项及源码审阅通过；这是界面与真实文件状态的有限验收，不是原生包或整产品交付。

## 实际变化

- 原文读取和音频接收分别选择，每次打开均默认关闭。授权成功必须回读 enabled、同一固定材料版本和两个相同许可值；只版本相同或旧许可状态不能显示成功。
- 关闭收尾期间，材料入口、方法入口和授权弹窗迟回均不能重新授权；高级连接也不能绕过。沿用既有 scope、私有路由和 App Navigator 上方的退休屏障。
- 候选及学习版本读取 Core 的真实媒体审阅状态：英文绑定匹配、已失配、文件不可用或尚未验证分别说明。绑定匹配不代表声音质量或权利已核验；文字与音频的提供方声明分开显示。
- 只改中文保留音频；英文未保存又恢复原样不产生失配。首次保存英文、顺序或数量变化后，Core 的失配持续生效，保存后改回和重开均不会恢复旧音频。
- 收到、保存、确认或拒绝候选只刷新状态，不自动选中或播放。确认幂等，重复确认不会多建学习版本。
- 保留正文、进度与播放、练习、底部词卡的顺序。词卡按钮实际 48×48，并提供展开语义；展开时释义、例句和来源共用有界滚动区。大字小屏仅在需要时将按钮移入视口，保留正文独立滚动和播放意图；材料双动作在宽度不足时换行。
- 正常说明文字 token 的实测对比度为白底约 5.07、词卡底约 4.68；不把禁用控件颜色当普通正文标准。无查词服务时说明不可用，不显示虚构词条、收藏或测评分数。

## 红测与修复

- 真实点击区原为 40×40：compact density 缩小了声明的 48 约束，改标准 density 后保留 48 断言。
- 大字长释义原在固定展开词卡的滚动区之外，且 ellipsis 仍可能截断。完整释义移入有界滚动区，并增加展开语义和实际末行可达检查。
- 对整张长词卡末端定位会让收起后的按钮出屏；旧快照独立实测按钮仍有焦点但无法命中。定位改为实际按钮，按视口上下越界判断，零动画，并在回调检查 mounted、scope、版本和展开状态。
- 375 宽、200% 字号的材料双动作 Row 真实右溢 32 像素，改 Wrap，保留动作顺序和真实可达断言。
- 首次截图临时加载真实字体曾改变正文滚动上限，使原偏移合法收敛为零。修测试为构造前稳定字体；长正文验证持续可滚动时偏移与首句不变，短正文验证合法收敛且内容仍可读，不为不可达像素修改产品布局。
- 历史组合测试曾长时间超时并出现 guarded 冲突；隔离和原默认命令随后未复现，原因未证实，不宣称修复 VM 或宿主。原失败保留，不提高超时、不删除断言。
- 独立夹具的旧 API 参数、混合路径分隔符、真实 IO 与 fake clock 调度、懒加载列表定位和滚过释义尾行等错误单独修正；不按夹具错误更改产品权限或状态语义。

## 范围与下一门

只用合成材料、静音 PCM、真实 FileMaterialStore/FileLearningStore、受控回调和离屏 Widget。没有用户材料、真实剪贴板、主界面输入、麦克风、相机、宿主声音或云请求。受控播放快照不是原生播放或专业发音准确率。

G3 才编译新八工具代理、核对 App 内实际产物、进行隐藏静音原生组合验证及准备 Windows 人工体验。Android 仍是单列的工程候选，不继承 Windows stdio/ACL 链；iPhone、Mac 未由本测试验收。词典服务、词句本、复习、看板、学习生成、共享、反馈与账号等完整产品能力不由本片补齐。未灰度、未发布。
