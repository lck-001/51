环境：官方 Emulator37.2.13 / API36 AOSP x86_64 rev2、WHPX、swiftshader，2核/2GiB；主机摄像头和麦克风均未接入。

## 修复依据与改动

| 问题 | 诊断证据 | 改动 |
| --- | --- | --- |
| 返回前台按钮禁用 | VM 显示 pending=0、background=false，而真实 UI enabled=false；仅请求 Element.markNeedsBuild 后立即恢复。修复前实际断言失败，补刷新后相同流程通过 | resumed 清除后台标记后显式刷新，未强制清空真实操作队列 |
| 有进度无画面 | GPU 输出日志显示 EGL context/GLES 创建失败；相同合成 MP4、同一镜像下旧输出两次黑屏 | 仅 Android 改用依赖公开支持的 mediacodec_embed + mediacodec Surface 输出；其他平台配置不变，依赖版本不变 |
| 导入结果提示被覆盖 | 排队生命周期暂停提示曾盖掉导入结果；另一次自动化失败实际是状态文本在屏幕外，已通过 VM/界面区分 | 状态修订计数保护新提示；无播放时不追加泛化暂停消息。测试读取状态前先滚到完整标题所在的顶部 |
| 退出稳定性 | 旧路径捕获一次 libmpv SIGSEGV；不能据单次栈确定全部根因 | Android Back 先等待幂等清理再退出；禁止重复清理或新媒体操作，逐项尝试释放，超时与最终失败分别显示；外部销毁仍仅尽力清理 |

临时原生调试日志订阅已移除。关闭中只显示“媒体操作已停用”，不冒称资源已经释放；超时不代表原生停止或操作已取消。最终清理失败不提示无效的普通重试。

## 复跑

模拟器已装包，合成文件已放 Downloads/ShiyuLab_M14 时执行；所有设备命令限定私有端口和明确虚拟设备。脚本拒绝默认 ADB 与未确认的真实设备，不安装、推送、索权或采集。

```console
python tools/android_probe_regression.py --adb <adb.exe> --port 5038 --serial <emulator-serial>
python tools/android_exit_regression.py --adb <adb.exe> --port 5038 --serial <emulator-serial> --cycles 3
```

SAF脚本明确不承担视频画面或原生退出验收。退出脚本检查回到桌面及对应进程窗口日志，不把少量未复现写成崩溃根治。独立QA为只读审查，设备运行由主负责人执行，见 M14-fix-qa.md。
