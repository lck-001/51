# 编辑表单的键盘顺序

原 Windows 界面从正文按 Tab 会先进入底栏“学习”，跳过已启用的保存按钮。真实 Widget 在相同视口、Windows 字体和 DPR2 下复现了这一结果：保存控件的完整焦点矩形与底栏相交，默认 ReadingOrder 按几何顺序先选底栏节点。只增加窗口高度、消除相交时，原代码会正常进入保存。

修复仅为材料编辑列表增加局部 `FocusTraversalGroup(WidgetOrderTraversalPolicy())`，按控件顺序遍历。禁用控件仍由框架跳过，保留其原有滚动回调。

- 新增六项仓库 Widget 回归，覆盖正反 Tab、禁用控件、保存动作、已保存状态显式再入后的确认遍历、底栏出口、多行文本输入，以及返回与材料页切换后的输入保留。Enter 证据限定框架键事件与平台文本输入边界。
