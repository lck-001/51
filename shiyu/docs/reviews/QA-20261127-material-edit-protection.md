# 材料未保存保护与编辑页返回入口

材料编辑到一半切到材料页，再点新增，原实现会直接清空标题和正文。本次让新增操作先复用既有的未保存确认框：继续编辑或关闭弹窗保留输入和正在编辑的草稿；只有明确放弃、页面所属范围及输入操作仍有效时，才清空表单。重复请求、保存确认中、页面退休及过期弹窗结果不会获得清空权限。

材料编辑页另补可见的“返回材料”箭头，调用既有返回处理。它与阅读页返回、底栏导航保持分开；保存、确认或其他返回处理中禁用。旧按钮回调在切页、换所属范围或退休后不执行，避免误触根退出。底栏“添加”仍只切页并保留当前编辑状态。

## 验证

- 原新增材料回归：导航保留输入通过，空材料页和已有材料列表的新增保护先各复现失败；原断言保留。
- 修复后覆盖取消、明确放弃、关闭弹窗、重复回调、编辑既有草稿后同一材料续存及退休后的迟到结果。
- 返回入口覆盖无修改返回、未保存继续／放弃、保存确认中禁用，以及跨页面、跨所属范围、退休后的旧回调。
- 最终格式后完整离屏测试：client_shell **58/58**、playback 验证项目 **119/119**，均 exit0。依赖及锁文件未变。

一次较长临时目录配置使两项缓存测试在进入 rename 测试门之前返回 cacheCorrupt；独立诊断确认派生临时文件路径达到273字符。换用明确短的独立临时目录后，原测试及两套完整回归通过，没有修改存储库或原测试断言；该环境失败保留，不归因于界面修复。

## 范围

这些是合成材料、独立文件存储及 headless Widget／集成回归，不是新版 Windows 原生鼠标键盘、安卓真机或 Apple 验收。此前普通 Windows 后台单次导航已实际进入材料表单，但对应旧构建，不能冒称包含本次修复。后续需重建新版包，再分别验证真实文字录入、保存确认、返回保护和恢复。真实英语生成、朗读与专业发音评分仍不属于本次已交付能力；未合并主分支或正式发布。
